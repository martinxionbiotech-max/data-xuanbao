# Evidence Registry

**Direct answer:** This registry records the documented performance evidence
referenced across this knowledge center — field test results, manufacturer
specifications and derived values — with their data type, source, date where
available, and verification status. It exists so a claim on one page can be
traced to its origin, and so nothing on this site is mistaken for an
independently verified universal fact.

## How to read the registry

| Field | Meaning |
| --- | --- |
| Evidence ID | Internal reference identifier used by pages citing the evidence |
| Data / Claim | What the evidence states |
| Data Type | One of the seven types in [Data Classification](data-classification.md) |
| Source | Where the evidence is published (main site page or official document) |
| Date | Test or publication date when recorded |
| Verification Status | Confirmed vs partially recorded (see below) |
| Related Material / Product | What the evidence applies to |

**Verification status meanings:** *Confirmed* = the cited source exists and the
numbers are taken from it. *Partially recorded* = the source exists but does not
publish all supporting test conditions, so the result cannot be generalized
beyond its stated application.

## Manufacturer specification references

Product specification values (dimensions, cell density, metal loading, mechanical
properties) cited on this site are **Manufacturer Specification** data type and
trace to the product pages on the [main site](https://xuanbaoenvironment.com/products/).
Where a main-site value is quoted, the page states the data type. Specification
values describe the product as manufactured — they are not field performance
guarantees.

## Engineering reference values

Ranges used for design guidance (temperature windows, space velocity ranges,
pressure drop rules, iodine number interpretation bands) are **Typical Value**
engineering references unless a page labels them otherwise. They describe what
is normally expected, not what any specific product guarantees. See
[Data Classification](data-classification.md) for the full rules.

## What this registry deliberately does not do

- It does **not** fabricate evidence IDs for claims without documented sources.
- It does **not** list laboratory, customer or certification names — none are cited on this site because none have been published in a verifiable form.
- It does **not** convert brochure statements into verified performance claims.
