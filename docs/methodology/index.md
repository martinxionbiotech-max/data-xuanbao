# Technical Data & Source Methodology

This page explains where the technical information in this knowledge center
comes from, how it is classified, and how uncertainty is handled. It exists so
that engineering decisions made with this content can be traced back to a
defined evidence basis.

## 1. Company data

Company-provided information (product specifications, application descriptions,
documented field tests) is used when it is available in official company
materials. Company-provided information is presented as **company-provided**,
not as independently verified fact. Where independent verification exists, the
source is recorded.

## 2. Laboratory data

Laboratory values (BET surface area, iodine number, catalyst activity) are
meaningful only together with their test conditions and method. A laboratory
result under one set of conditions does not transfer to another application
without re-testing.

## 3. Field data

Field data comes from specific industrial applications at specific plants under
specific operating conditions. The knowledge center always states the
application, pollutant, inlet value, outlet value and — where available — test
date, test conditions and testing organization. A field result demonstrates
that a material performed in one application; it is **not** a universal
performance guarantee.

## 4. Public technical sources

Where general technical knowledge (mechanisms, engineering practice) is
explained, it is based on established technical literature and engineering
practice. Public technical sources are referenced at evidence levels — see
[Sources & Evidence](sources.md).

## 5. Standards

Standards are cited by number, title, issuing organization and jurisdiction.
A standard is never presented as current without verification — see
[Compliance & Standards](../compliance/index.md).

## 6. Literature

Academic and technical literature is used for mechanisms and reference values.
Literature values are labeled as such and are not confused with measured
company data.

## 7. Derived calculations

Values such as percentage reductions are calculated from documented source
data (for example inlet vs outlet concentrations from a field test record).
Derived values are labeled **Derived Value** and the source data is stated.

## 8. Unverified / provisional data

Information that cannot yet be verified is labeled as requiring verification,
or is withheld entirely. The knowledge center does not publish:

- invented production capacities
- fabricated certifications or customers
- fabricated test results
- unverified standards claims
- invented academic references

## How uncertainty is marked

- **Verified** — source recorded and checkable.
- **Company-provided** — official company information, not independently confirmed.
- **Requires verification** — plausibility uncertain, needs confirmation before use.
- **Not published** — unverifiable claims are excluded rather than hedged.

For the formal data-type classification used on technical pages, see
[Data Classification](data-classification.md).
