# 证据注册表（中文译本）

> **中文译本，以英文页为准。** 本页是 [Evidence Registry（证据注册表）](evidence-registry.md) 的中文翻译，数据相同。如中英文表述有出入，以英文页为准。

**直接回答：** 本注册表记录本知识中心引用的、有文档依据的性能证据——现场测试结果、制造商规格与推导值——并标注其数据类型、来源、日期（如有）与核验状态。它存在的意义，是让任一页面上的声明都能追溯到出处，并确保本站没有任何内容被误当作独立核实的普遍事实。

## 如何阅读本注册表

| 字段 | 含义 |
| --- | --- |
| 证据编号 | 引用该证据的页面所使用的内部引用标识 |
| 数据 / 声明 | 该证据所述内容 |
| 数据类型 | [数据分类](data-classification.md) 中七种类型之一 |
| 来源 | 该证据的发布位置（主站页面或官方文件） |
| 日期 | 测试或发布日期（如有记录） |
| 核验状态 | 已确认 vs 部分记录（见下） |
| 相关材料 / 产品 | 该证据适用的对象 |

**核验状态含义：** *已确认* = 所引用来源存在，且数字取自该来源。*部分记录* = 来源存在但未公布全部支撑性测试条件，因此该结果不能推广到其所述应用之外。

## 制造商规格引用

本站引用的产品规格值（尺寸、孔密度、贵金属负载量、机械性能）为 **制造商规格** 数据类型，追溯至 [主站](https://xuanbaoenvironment.com/products/) 的产品页。凡引用主站数值处，页面均会标注数据类型。规格值描述的是产品出厂状态——并非现场性能保证。

## 工程参考值

用于设计指导的区间（温度窗口、空速区间、压降规则、碘值解读区间）为 **典型值** 工程参考，除非页面另有标注。它们描述通常预期情况，而非任何特定产品的保证。详见 [数据分类](data-classification.md)。

## 本注册表明确不做的事

- 不为缺乏文档来源的声明**编造**证据编号。
- 不列出实验室、客户或认证名称——本站从未以可核实形式公布过这些，故一律不引用。
- 不把宣传册表述转化为经核实的性能声明。
